How to print so the labels line up
  1. Click Print Labels. In the print dialog, either pick your printer, or save a PDF first: Microsoft Print to PDF on Windows, PDF ▾ → Save as PDF on Mac, or Save as PDF in Chrome. Use paper A4, margins None, scale 100%.
  2. To print a saved PDF, open it in Adobe Acrobat Reader → Print → Page Sizing & Handling: Size → Actual size (not Fit or Shrink), tick Choose paper source by PDF page size, Orientation Auto.
  3. Check that the preview reads 8.27 x 11.69 Inches (A4) and shows one page per sheet, then print.
Don't print straight from Safari: it adds its own margins, which crops the top row and puts a blank page after every sheet.

🎯 To calibrate: print the Alignment Test on plain paper and hold it behind a label sheet against a window. If the outlines are off by D mm at the last row, change Row Gap by D ÷ 9 (drifting down → smaller gap, drifting up → bigger gap). Use Top/Left to move everything at once.
