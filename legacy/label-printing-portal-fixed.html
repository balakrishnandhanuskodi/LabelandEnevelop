📋 Printing Instructions:

  • Label Size: 100mm × 44mm (12 labels per A4 sheet)
  • When printing, ensure "Scale" is set to 100% or "Actual Size"
  • Disable "Headers and Footers" in print settings
  • Set margins to "None" or "Minimum"
  • Use A4 paper size in portrait orientation
