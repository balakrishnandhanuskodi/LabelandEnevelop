How to print so the labels line up
  1. Click Print Labels. Pick your printer, or save a PDF first (Microsoft Print to PDF on Windows, PDF ▾ → Save as PDF on Mac, Save as PDF in Chrome). Use A4, margins None, scale 100%.
  2. To print a saved PDF, open it in Adobe Acrobat Reader → Print → Size → Actual size, tick Choose paper source by PDF page size, Orientation Auto.
  3. The preview should read 8.27 x 11.69 Inches (A4), one page per sheet.
Print the Alignment Test on plain paper, not on a label sheet. Don't print straight from Safari: it adds its own margins and shifts the labels. NovaJet sheets are for inkjet: set the printer's paper type to Labels if it has one.

Text padding inside label

Alignment Test prints numbered outlines only (no addresses). Print it on plain paper, put a label sheet on top and hold both against a window: each outline should sit on a label.
Or measure a blank sheet with a ruler: Top = paper top edge → first label, Left = paper left edge → first label, Row gap = space between labels going down, Column gap = space between the two columns.
If the outlines are off by D mm at the last row, change Row gap by D ÷ 5. Use Top/Left to move everything at once. Saved on this computer.
